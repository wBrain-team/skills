# Clean Code

[← Diretrizes](guidelines.md)

- Nomes descritivos para variáveis, funções e classes.
- Funções com responsabilidade única e curtas.
- Sem código duplicado — extraia abstrações quando necessário.
- Comentários apenas para o "porquê", nunca para o "como".
- Siga as convenções de estilo da linguagem (Ruff no backend, ESLint + Prettier no frontend).

## Idioma

- Todo **código** é escrito em **inglês**: variáveis, constantes, funções, classes, arquivos,
  tabelas, colunas, enums, rotas/URLs, chaves de tradução, nomes de migrations e branches.
- O idioma do **conteúdo** é livre: textos exibidos ao usuário (via [i18n](../frontend/i18n.md)),
  mensagens de erro, dados fake, comentários e documentação.
