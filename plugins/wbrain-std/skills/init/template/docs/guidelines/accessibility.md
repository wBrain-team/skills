# Acessibilidade

[← Diretrizes](guidelines.md)

- Todo elemento interativo (`<button>`, `<a>`) deve ter `aria-label` descritivo quando não houver texto visível.
- Botões com apenas ícone devem ter `aria-label` **e** `title` (tooltip nativo).
- Nunca adicione botões de navegação sem destino funcional — remova-os até que estejam implementados.
